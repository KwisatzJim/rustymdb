# Changelog

## 0.1.0 — Initial public source release

- IMDb-first local title and People search, ratings, credits and TV episodes.
- Optional TMDB details, photos, expanded credits, trailers, recommendations and collections.
- Local person/title navigation based on provider-supplied IMDb IDs.
- Shared watchlist with watched status, notes and filters.
- Manual and scheduled maintenance, verified backups and opt-in retention.
- Portable restore preparation and Linux service examples.
- MIT source license and Linux/macOS build checks.
