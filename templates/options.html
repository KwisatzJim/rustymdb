Set up your TMDB account

  1. Create a free TMDB account, verify your email, and sign in.
  2. On a desktop browser, open Settings → API and request API access. Choose the appropriate developer/non-commercial use option for this personal server.
  3. Review TMDB's terms and complete its application form. Describe the application as a private, self-hosted movie information browser. Use your actual application/contact information; do not invent a public website.
  4. Once access is approved, return to API settings. Copy either the API Read Access Token (recommended) or the API Key (v3 auth).
  5. Paste just one credential below, then select Save and verify. These are API credentials, not your TMDB account password.

Leave both fields blank to keep and test the existing credential. Saved values are never returned to the browser. Use a trusted Tailscale/HTTPS connection when entering credentials.

Automatic maintenance

Schedules run while this server is running, using the same job runner as the Maintenance tab. Only one job runs at a time. Overdue jobs wait for the runner to become available; missed intervals are combined into one run.

Newly enabled or changed schedules first run after the selected interval. Saving an unchanged interval preserves its next run. Disabling a schedule does not cancel a job already running. Failed jobs wait until the next interval; see Maintenance for output.

Manual backups remain until you remove them. Scheduled backups follow the retention setting below. Full dataset refreshes can take a long time and download several gigabytes. Settings and next-run times are included in database backups; an enabled overdue schedule runs once after a restore.
