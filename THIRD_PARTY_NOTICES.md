## IMDb

IMDb data is retrieved from the official IMDb datasets and, where available,
IMDb's web services. IMDb names and marks belong to their respective owners.
Review the [dataset documentation](https://data.imdb.com/non-commercial-datasets/)
and its linked licensing terms before downloading or using the data. The MIT
license for this application does not relicense provider data.

## TMDB

This product uses the TMDB API but is not endorsed or certified by TMDB.

`static/tmdb-logo.svg` is the approved TMDB blue short logo, included unchanged
for API attribution. It is not original MIT-licensed application artwork.
See [TMDB's attribution guidance](https://developer.themoviedb.org/docs/faq)
and [approved logos](https://www.themoviedb.org/about/logos-attribution).
Photos, posters, biographies and other TMDB content are retrieved at runtime;
none are bundled as sample data in this source distribution.
